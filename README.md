### Research Interests

I work toward robust and generalizable robotic agents that can perceive and act in complex, real-world environments.

- **Reinforcement learning for dexterous manipulation** — learning reliable skills for contact-rich tasks.
- **Real-to-sim-to-real transfer** — using real-world data and digital twins to improve simulation-trained behavior.
- **Humanoid vision-based control** — enabling humanoids to perceive and interact with their surroundings.
- **Robot foundation models** — developing generalizable capabilities for long-horizon tasks.

### Selected Project

#### [Dex-Keypoint: Webcam-Based Dexterous Hand Teleoperation](https://github.com/soonawg/Dex-Keypoint)

A simulation-only project that tracks hand motion with MediaPipe and retargets finger movements to an Allegro Hand V3 in a MuJoCo tabletop scene. It does not control physical robot hardware.
